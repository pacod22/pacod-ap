# Usage limits, storage and version history

Every plan has limits on storage, the size of a single attachment and how long
earlier versions of a note are kept. Free also limits the number of notes. The
exact limits per plan are reference facts.

## Storage

Storage counts attachments (images, PDFs, audio) and the notes themselves. On
Team, storage is pooled: the allowance per user is added up across the
workspace, so a heavy user can use more than their share.

When an account reaches its storage limit, existing notes stay readable and
editable, but new attachments are refused until space is freed or the plan is
upgraded.

## Attachment size

A single file larger than the plan's maximum attachment size cannot be added to
a note. Split large files or store them elsewhere and link to them.

## Version history

Nimbus Notes keeps earlier versions of every note. A version can be restored
from the note's **History** panel for as long as it is kept; the retention
period depends on the plan.

## Team workspaces

A Team workspace can hold a fixed maximum number of members. Larger
organisations use several workspaces and connect them through the admin console.
