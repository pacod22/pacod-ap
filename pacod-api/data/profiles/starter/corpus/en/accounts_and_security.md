# Accounts, sign-in and security

## Signing in

Accounts sign in with an email address and a password, or with Google. Team
workspaces can also require single sign-on through the organisation's identity
provider. Passwords must have a minimum length (a reference fact) and are never
sent to Nimbus Notes staff.

## Two-step verification

Two-step verification with an authenticator app can be switched on under
**Settings → Security**. On Team, administrators can make it mandatory for all
members.

## Lost access

If a user cannot sign in, the **Forgot password** link sends a reset email. The
support desk never asks for a password and cannot read notes; it can only help
recover access after the account owner has proved control of the email address.

## Closing an account

An account can be closed under **Settings → Account → Close account**. The data
of a closed account is kept for a fixed number of days, during which the account
can be reopened, and is then deleted permanently. An export of all notes can be
downloaded before closing.

## Exporting data

All notes can be exported at any time as Markdown or as a ZIP archive with the
attachments. Exports are available on every plan, including Free.
