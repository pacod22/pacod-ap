# Contributing

Thank you for your interest in pacod-ap.

## Code contributions

pacod-ap does not accept contributions at the moment: no pull requests, patches, documentation
changes, translations or agent profiles. Pull requests will not be reviewed or merged. This may
change later; this file will say so when it does.

## Bug reports and feature suggestions

Both are welcome. Open an issue in the repository's **Issues** tab. Search the existing issues
first: if yours is already there, add what you know to it instead of opening a new one.

A bug report helps most when it gives:

- the version or commit, and which part is affected: the chat API, the admin API, the MCP server,
  ingestion, the workers (improvement loop, newsletter), the SvelteKit frontend, or the deployment
  files (compose, Caddy, monitoring);
- how you run it, and the agent (profile) and language involved, if the bug concerns one;
- the steps to reproduce, and what happens compared with what should happen;
- the error messages and log lines.

A feature suggestion helps most when it says:

- what you are trying to do, and what stops you today;
- how you would expect the platform or the agent to behave;
- what you use instead, if anything.

Issues are public. Remove keys, tokens, passwords and other people's conversations from everything
you post. Placeholders are enough.

## Security vulnerabilities

Do not report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
